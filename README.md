# 20 Páginas Web

Colección de 20 interfaces modernas creadas con HTML, CSS y JavaScript.

- index.html: portada y selector de proyectos.
- pagina-1.html a pagina-20.html: 20 páginas independientes.
- assets/style.css: sistema visual compartido.
- assets/script.js: microinteracciones.

Preparado para GitHub Pages. Las fotografías de demostración se cargan desde Unsplash mediante URL.
